# 10. Уроки из claude_asist

Источник: https://github.com/OlegYaro/claude_asist (`README.ru.md` «Что выяснилось», `reviewer.ts`,
`paths.ts`, `hook-server.ts`, `limit-estimate.ts`). Найдены на практике; каждая ломала бы
приложение молча. Перед фазой 0 — прочитать эти файлы в том репозитории, если он доступен.

| # | Ловушка | Что делаем в RegWatch |
|---|---|---|
| 1 | Переменная `CLAUDE_CODE_CHILD_SESSION` и другие `CLAUDE_*` (наследуются, если приложение запущено из сессии Claude Code, переживают login shell) → CLI считает себя вложенным и **не пишет транскрипт** | `env.ts`: вырезать все `CLAUDE_*` и `CLAUDECODE` перед запуском; тест `env.test.ts` |
| 2 | Electron из Finder не видит PATH пользователя | Окружение из login shell (`$SHELL -ilc env`), затем стандартные пути к `claude`; путь можно задать в «Дополнительно» |
| 3 | `--allowedTools` через запятую не разбирает правила со скобками | Каждое правило — отдельный аргумент массива `execFile` |
| 4 | Глобальное `allow: ["Bash"]` пользователя расширяет права дочернего процесса | `--restricted` (не читает пользовательские настройки) + явный `--tools`; проверить в фазе 0 |
| 5 | Интерактивные разрешения вешают процесс | `--permission-mode dontAsk`: всё неразрешённое отклоняется сразу |
| 6 | Авто-режим сам одобряет рискованное | Авто-режим не используется никогда |
| 7 | Субагенты CLI уходят в фон, процесс заканчивается раньше | Модели запрещён `Agent`/`Task`; изоляция — отдельными процессами `claude -p` из кода |
| 8 | Транскрипт пишется с задержкой | Источник правды — `structured_output`/событие `result`, не транскрипт |
| 9 | В незнакомой папке интерактивный CLI спрашивает о доверии | Работаем только `-p`; в фазе 0 проверить, что `-p` в новой рабочей папке не ждёт диалога; если ждёт — записать и найти флаг/настройку |
| 10 | `/model` в живой сессии меняет глобальные настройки | Модель только флагом `--model` |
| 11 | Ответ модели надо разбирать надёжно | `--output-format json`/`stream-json` + `--json-schema`, поле `structured_output`, проверка ajv |
| 12 | Секреты нельзя держать в файлах и renderer | `safeStorage`, только main-процесс |
| 13 | Расход по сессии сервер не делит; общий % — из `rate_limits.five_hour` статус-строки | В `-p` статус-строки нет → источник лимита выяснить в фазе 0 (см. `02-architecture.md` §8); веса токенов взять из `limit-estimate.ts` |
| 14 | Путь Unix-сокета на macOS ≤ 104 байт | В RegWatch сокетов нет; если появятся — `/tmp/rw-<uid>/` |
| 15 | Одна копия бота/приложения | `app.requestSingleInstanceLock()` |
