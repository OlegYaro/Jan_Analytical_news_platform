# 06. Установка и первый запуск

## 1. Что нужно заранее (проверяет `npm run doctor`)

| Что | Как проверить | Если нет |
|---|---|---|
| Mac, macOS 13+ | — | — |
| Node.js 22.18+ (рекомендуется 24) | `node -v` | Скачать установщик с nodejs.org (LTS) |
| Git | `git --version` | macOS предложит установить сам при первом вызове |
| Claude Code, вход выполнен | `claude --version`, затем `claude -p "ok"` отвечает | `npm install -g @anthropic-ai/claude-code`, затем `claude` и вход |

Xcode, Python и компиляторы **не нужны** (INS-02): в проекте нет нативных модулей.
Если `git` предлагает установить Command Line Tools — это нормально, установка только для git.

## 2. Установка (INS-01)

```bash
git clone https://github.com/OlegYaro/Jan_Analytical_news_platform.git
cd Jan_Analytical_news_platform
npm install
npm run app
```

`npm run app`: сборка → копия в `/Applications/RegWatch.app` → запуск. Приложение подписано ad-hoc:
при первом запуске macOS может сказать «не удаётся проверить разработчика» — README объясняет:
Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

Если нет прав на `/Applications` — скрипт кладёт приложение в `~/Applications` и говорит об этом.
Если приложение уже запущено, скрипт сам его закрывает перед заменой; изнутри RegWatch скрипт не запускается (ошибка с пояснением).

### Первый запуск: мастер (INS-04)

Окно «Первый запуск RegWatch», 8 шагов (названия — как в окне): «Проверка компьютера» → «Папка для отчётов» →
«Почта» (обязательное тестовое письмо, CFG-14) → «Что искать» → «Страны» → «Расписание» → «Проверка источников»
(можно пропустить) → «Готово» (кнопка «Сделать пробную проверку сейчас», затем «Завершить»). Кнопки: «Назад», «Дальше».
Подробнее — `05-ui-and-settings.md` §2 и `README.ru.md` §4.

## 3. `npm run doctor`

Печатает по-русски таблицу ✅/❌ и что делать. Проверки:
1. Версия Node ≥ 22.18.
2. Бинарь `claude` найден (через login shell, затем стандартные пути: `~/.claude/local/claude`,
   `~/.local/bin/claude`, `/opt/homebrew/bin/claude`, `/usr/local/bin/claude`, `~/.npm-global/bin/claude`).
3. `claude --version` — записать версию.
4. Вход выполнен: `claude -p "Reply with OK" --output-format json` → `result` содержит OK (стоит
   немного лимита; один раз).
5. Нужные флаги есть в `claude --help`: `--json-schema`, `--permission-mode`, `--allowedTools`,
   `--disallowedTools`, `--tools`, `--output-format`, `--setting-sources`, `--strict-mcp-config`. (`--max-turns` в справке нет, но работает — FINDINGS; `--restricted` не используется.)
   Отсутствие обязательного флага → ❌ «Обновите Claude Code: `claude update`».
6. Запись в рабочую папку возможна.
Тот же модуль показывает результат на первом шаге мастера.

## 4. Обновление (INS-06)

```bash
cd Jan_Analytical_news_platform
git pull
npm install
npm run app
```
Настройки, страны, журнал и архив сохраняются (они вне папки репозитория).

## 5. Удаление

Удалить `/Applications/RegWatch.app`; по желанию — `~/Library/Application Support/RegWatch`
(настройки) и рабочую папку (архив). Пароль почты лежит зашифрованным в папке настроек (`secrets.json`), ключ шифрования держит macOS в «Связке ключей» (запись RegWatch; так работает `safeStorage`). Если приложение стояло в `~/Applications`, удалять нужно его. Из «Объектов входа» (Системные настройки → Основные) RegWatch убирается вручную.
