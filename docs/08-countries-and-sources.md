## Классы органов (CTY-09, вариант B)

Класс задаёт, насколько строго отбор относится к акту органа: **1** — финансовый регулятор, акты проходят отбор всегда; **2** — общий законодатель, решает отбор по заголовку и банковские слова в тексте; **3** — прочие органы, берутся только при банковских словах в тексте. Список виден и редактируется в карточке страны («Органы и уровень отбора»). Названия органов — как в поле `issuer` lex.uz; сопоставление по подстроке без учёта регистра на uz/ru.

**Узбекистан (UZ):**

| Орган (как в источнике) | Класс |
|---|---|
| Центральный банк (Правление ЦБ, Markaziy bank) | 1 |
| Национальное агентство перспективных проектов (рынок капитала) | 1 |
| Закон (акты Олий Мажлиса, законы) | 2 |
| Президент | 2 |
| Кабинет Министров | 2 |
| Все остальные органы (Налоговый комитет, Минздрав, Минцифры, Минюст и т. д.) | 3 |

**Остальные страны (KZ, KG, TJ, TM, GE, AM, AZ, MN):** списки органов пока не составлены — все органы считаются классом 2 (без потерь, но дороже). Составить список для страны — после проверки её источников (фаза 6/9): центральный банк и регулятор рынка капитала → 1, парламент, президент/глава государства, правительство → 2, остальные → 3. Номера, названия органов по памяти не вписывать.

## Типы актов для отслеживания в каждой стране

Для каждой страны пользователь отслеживает (канал А) основные акты следующих типов:

1. закон о банках и банковской деятельности;
2. закон о центральном банке;
3. закон об акционерных обществах;
4. закон о валютном регулировании;
5. закон о противодействии отмыванию денег (AML/CFT);
6. закон о гарантировании вкладов;
7. основное положение центрального банка о корпоративном управлении в банках.

Конкретные акты (название в оригинале, номер, ссылка, дата последней редакции) **находит скилл
`/discover-sources`** (режим поиска отслеживаемых актов, требование SRC-09), а пользователь их
подтверждает кнопкой «Добавить» в карточке страны. Номера и ссылки по памяти в данные не
вписываются; сейчас в стартовых данных только два акта Узбекистана из таблицы выше.
