# 07. Тесты и приёмка

## 1. Юнит-тесты (`npm test`, NFR-17)

Обязательные наборы (имитация сети и `claude` — заглушками):
- `ledger.test.ts` — ключи, повторы, новая стадия → обновление, пробный прогон не пишет.
- `scheduler.test.ts` — следующий запуск по дням/времени, переход на летнее время (Europe/Warsaw),
  догон пропущенного слота, не двойной запуск одного слота.
- `run-state.test.ts` — возобновление с этапа/акта, атомарная запись.
- `evidence.test.ts` — нормализация апострофов (`ʼ'’ʻ`), кавычек, пробелов; даты в разных форматах
  и языках; номер в цитате; ложная цитата → ❌.
- `completeness.test.ts` — потерянный кандидат → нет итогового статуса.
- `numbers.test.ts` — EN/RU: изменённое число/дата/URL → блок.
- `profile.test.ts` — rss/html_list/json_api на сохранённых HTML; < 3 документов → не ✅.
- `anomaly.test.ts` — 0 документов при медиане > 0 → `failed:parser`.
- `digest.test.ts` — нет карточек → нет письма; сбой 1 раз → нет письма; 2 раза → письмо о сбое.
- `stage-profiles.test.ts` — аргументы CLI: каждое правило `--allowedTools` отдельным аргументом;
  `Bash`, `Agent`, `Write` всегда в `--disallowedTools`; `dontAsk` всегда.
- `mail-gate.test.ts` — без проверенной почты прогон/расписание блокируются, пробный прогон разрешён.
- `env.test.ts` — `CLAUDE_*` и `CLAUDECODE` вырезаны.
