# 01. Требования

Каждое требование имеет ID. Приоритет: **M** — обязательно, **S** — желательно, **C** — можно позже.
Все M и S должны быть реализованы и отражены в `docs/TRACEABILITY.md`.

Эталон, на котором проверяется приложение: `docs/golden/UZ-3254-2.md` (поправка ЦБ Узбекистана
к Положению о корпоративном управлении в коммерческих банках, вступает в силу 13.01.2027).
Выводы из эталона, на которых построены требования:
- изменение — **акт регулятора**, а не закон → отслеживаются все уровни актов;
- в СМИ о нём **не писали** → основной канал — первичная правовая база, а не новости;
- оригинал только на **узбекском**, русская версия не обновлена → читать оригинал, переводить самим;
- у акта цепочка поправок (3254 → 3254-1 → 3254-2) → ключ повторов — номер регистрации;
- акт опубликован 12.10.2026, а вступает в силу 13.01.2027 → сообщать при публикации.
