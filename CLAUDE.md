# CLAUDE.md

Этот файл — правила для Claude Code при работе в этом репозитории.

## Что строим

**RegWatch** — десктопное приложение для Mac (Electron + TypeScript + React). Оно по расписанию
проверяет изменения в регулировании (по умолчанию — банковском и корпоративном, для PE-инвестора в
капитал финансовых институтов) в девяти странах Центральной Азии, Кавказа и Монголии и присылает на e-mail дайджест **только если есть что-то новое**. Вся работа с
моделью идёт через установленный у пользователя Claude Code CLI (`claude -p`), по подписке,
без API-ключа.

Пользователь — **не программист**. Всё, что можно настроить, настраивается в окне приложения
понятными полями на русском. Установка: `git clone` → `npm install` → `npm run app`.

ошибается — исправь документ и запиши причину в `docs/FINDINGS.md`.

## Языки

- Интерфейс, сообщения об ошибках, README для пользователя, комментарии в коде — **русский**.
- Скиллы, промпты, JSON-ключи, исходный отчёт — **английский**.
- Перевод отчёта на русский — отдельный этап (`/translate-ru`).

## Жёсткие правила

1. **Оркестратор — код, не модель.** Порядок стран, статусы, повторы, бюджет, проверки полноты
   и цитат делает TypeScript. Модель вызывается только для узких этапов через скиллы.
2. **Модель запускается только `claude -p`** (без PTY, без интерактивного TUI), всегда с
   `--permission-mode dontAsk`, явными `--tools`, `--allowedTools` (каждое правило отдельным
   аргументом), `--disallowedTools`, `--output-format json`, `--json-schema`, таймаутом процесса.
   Права этапов — таблица в `docs/02-architecture.md` §6. Bash и Agent модели запрещены везде.
3. **Никаких нативных модулей** (node-pty, Swift, node-gyp). Установка не должна требовать Xcode.
4. **Ни одной настройки, которую нужно править в файле.** Каждая — поле в окне с подсказкой.
5. **Промпты и скиллы пользователь не редактирует.** Значения настроек подставляются как
   переменные. Скиллы копируются из `skills/` в рабочую папку при старте.
6. **Полнота важнее экономии.** Нельзя «упрощать» проверки полноты, цитат и верификации ради
   токенов.
7. **Никаких выдуманных данных в тестах приёмки.** Эталон — только `docs/golden/`.
8. Секреты — только через `safeStorage`; в renderer не передаются.
9. Окружение для `claude`: из login shell, с вырезанными переменными `CLAUDE_*` и `CLAUDECODE`
   (см. уроки).

## Команды (создать в фазе 1)

```bash
npm install        # зависимости (без нативной сборки)
npm run dev        # разработка
npm run typecheck  # tsc для main/preload/shared и renderer
npm test           # node:test, чистая логика
npm run doctor     # проверка окружения пользователя (Node, claude, вход в аккаунт)
npm run app        # сборка + установка в /Applications/RegWatch.app
npm run golden     # прогон эталонов (docs/07 T-16)
```

Проверка любой правки: `npm run typecheck && npm test`. Не запускай `npm run app`, если сессия
открыта изнутри установленного RegWatch.

## Как работать

- Иди по фазам из `docs/09-implementation-plan.md`, веди список задач, в конце фазы — её
  критерии готовности и обновление `TRACEABILITY.md`.
- Не помечай требование `done` без теста или ручной проверки, описанной в TRACEABILITY.
- Если требование невыполнимо как написано (например, флаг CLI не существует) — не обходи молча:
  реализуй описанный в документах запасной вариант, запиши в FINDINGS и пометь в TRACEABILITY.
