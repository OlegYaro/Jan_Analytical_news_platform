# RegWatch — инструкция для пользователя

RegWatch следит за изменениями в законах и правилах девяти стран (Узбекистан, Казахстан, Кыргызстан, Таджикистан, Туркменистан, Грузия, Армения, Азербайджан, Монголия) и присылает вам письмо. По умолчанию программа ищет то, что важно для инвестора в капитал банков: банковское и корпоративное право, владение и контроль, дивиденды, налоги, валютные правила, борьба с отмыванием денег. Тему можно поменять.

Программист быть не нужно. Всё настраивается в окне программы. Единственное, что делается в «Терминале», — установка (несколько команд, их можно копировать).

## 1. Что делает программа

- По расписанию (например, по понедельникам в 08:00) заходит на официальные сайты законодательства и регуляторов выбранных стран.
- Находит новые и изменённые акты, читает их и отбирает те, что подходят под вашу тему.
- Для каждого важного акта пишет краткий разбор: что изменилось, когда вступает в силу, есть ли переходный период. Каждое значение программа сверяет с текстом акта.
- Присылает вам **одно письмо — и только если нашлось что-то новое**. Нет изменений — нет письма.
- Всю «умную» работу выполняет Claude Code, установленный у вас на компьютере, по вашей подписке Claude. Отдельный ключ или оплата не нужны.

### Как выглядит письмо

Пример оформления (текст условный):

```
Тема: RegWatch: UZ — 2 существенных, 1 для сведения, 1 не удалось проверить

🇺🇿 Узбекистан — 2 существенных, 1 для сведения, 1 не удалось проверить
Корпоративное управление в банках
Пост. Правления ЦБ № 24/2 от 17.09.2026, рег. МЮ № 3254-2 от 09.10.2026
Вступает 13.01.2027, переходного периода нет
Изменяет Положение рег. № 3254. Изменений: 10 — 🔴 3 · 🟠 4 · ⚪ 1
🔴 п. 8 — краткое описание самого важного изменения (внедрить сложно)
Читать: изменения · действующая редакция · новая редакция

Для сведения
· Название акта — номер, дата — ссылка

⚠ Не удалось проверить
· Название акта — причина — ссылка

Проверено 9 из 9 стран · Не является юридической консультацией · Подробно в приложении
```

Что означают пометки:

| Пометка | Значение |
|---|---|
| 🔴 | Значимое изменение для вашей точки зрения («Для кого оценивать значимость»). В письмо попадают самые важные строки, не больше трёх на акт; остальное — в приложении |
| 🟠 | Менее значимое изменение |
| ⚪ | Незначимое изменение |
| «внедрить сложно» | Приписка у 🔴-строки: изменение трудно выполнить |
| **Для сведения** | Акты, которые в тему подходят, но существенного для вас в них нет. Одна строка на акт: название, номер, дата, ссылка |
| **⚠ Не удалось проверить** | Акт найден, но программа не смогла его надёжно разобрать (нет текста акта, ошибка, результат не подтвердился при проверке). Такие акты не пропадают: вы видите их и ссылку, чтобы посмотреть самому |
| **⚠ не подтверждено** | Стоит рядом с актом или полем: при сверке с текстом акта значение не удалось подтвердить. Относитесь к нему осторожно и откройте акт по ссылке |
| «Проверено N из N стран» | Сколько стран удалось проверить в этот раз. Страны со сбоем перечислены рядом |

Если выбран русский язык отчёта, часть строк переводится с английского. Если у акта нет официального русского текста, в письме есть пометка «перевод неофициальный».

## 2. Что нужно заранее

| Что | Как проверить в «Терминале» | Если нет |
|---|---|---|
| Mac (macOS 13 или новее) | — | — |
| Node.js версии 22.18 или новее | `node -v` | Скачайте установщик «LTS» на сайте https://nodejs.org и установите |
| Git | `git --version` | Если Git нет, macOS сам предложит его установить — согласитесь (это нужно только для Git) |
| Claude Code, и вы в нём вошли в свой аккаунт | `claude --version` | Установка — ниже |

**Xcode и другие программы для разработчиков не нужны.**

«Терминал» — это программа на вашем Mac: нажмите Cmd+Пробел, наберите «Терминал», нажмите Enter.

### Если Claude Code ещё не установлен

В «Терминале» выполните:

```bash
npm install -g @anthropic-ai/claude-code
```

Затем наберите `claude` и нажмите Enter. Программа попросит войти в аккаунт Claude — следуйте её подсказкам. Когда вход выполнен, выйдите из него командой `/exit` и продолжайте.

Проверьте, что всё работает:

```bash
claude -p "ответь одним словом: ок"
```

Если пришёл ответ — всё в порядке.

## 3. Установка

В «Терминале» выполните по очереди:

```bash
git clone https://github.com/OlegYaro/Jan_Analytical_news_platform.git
cd Jan_Analytical_news_platform
npm install
npm run app
```

- **Первая команда** скачивает программу. Затем `cd Jan_Analytical_news_platform` заходит в скачанную папку.
- **`npm install`** скачивает всё нужное для работы. Это занимает несколько минут. Компиляторы не требуются.
- **`npm run app`** собирает программу, копирует её в «Программы» (`/Applications/RegWatch.app`) и запускает. Первый раз это тоже занимает несколько минут.

Если у скрипта нет прав на папку «Программы», он поставит RegWatch в `~/Applications` (папка «Программы» внутри вашей домашней папки) и скажет об этом.

Хотите проверить компьютер до установки? Выполните `npm run doctor`: программа напишет по-русски, что в порядке (✅), а что нет (❌), и что делать.

### «Не удаётся проверить разработчика»

При первом запуске macOS может написать «не удаётся проверить разработчика» и не открыть RegWatch. Это нормально: программа собрана на вашем компьютере и не имеет платной подписи Apple. Что сделать:

1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
2. Прокрутите вниз до сообщения про RegWatch и нажмите **«Всё равно открыть»**.
3. Подтвердите паролем или отпечатком пальца.

После этого RegWatch открывается как обычная программа. Сообщение показывается только один раз.

Значок RegWatch появится в строке меню (вверху экрана). Если закрыть окно, программа продолжит работать в строке меню — так и должно быть: проверки по расписанию идут, пока программа запущена. Значок в строке меню содержит пункты «Проверить сейчас», «Открыть RegWatch», «Выйти».

## 4. Первый запуск: мастер настройки

При первом запуске открывается окно «Первый запуск RegWatch». В нём 8 шагов; сверху видно, на каком вы шаге. Кнопки внизу: «Назад», «Дальше», на последнем шаге — «Завершить». Всё сохраняется само, кнопки «Сохранить» нет (появляется «Сохранено ✓»). К любому шагу можно вернуться кнопкой «Назад», а все настройки потом меняются в разделе «Настройки».

### Шаг 1. Проверка компьютера

Программа проверяет: Node, найден ли Claude Code, выполнен ли вход, есть ли нужные возможности Claude Code, можно ли писать в рабочую папку. У каждой строки ✅ или ❌. У ❌ есть подсказка «Что делать». Выполните её и нажмите **«Проверить снова»**. Пока обязательные проверки не пройдены, кнопка «Дальше» недоступна.

### Шаг 2. Папка для отчётов

Здесь хранятся отчёты и архив проверок. По умолчанию это папка `RegWatch` в вашей домашней папке (`~/RegWatch`). Если хотите другую — **«Выбрать другую»**. Лучше не выбирать «Документы», «Рабочий стол» и «Загрузки»: macOS защищает их и будет задавать лишние вопросы. Кнопка **«Открыть в Finder»** открывает папку.

### Шаг 3. Почта

Этот шаг **обязателен**: без настроенной почты регулярная проверка не запустится, а «Дальше» станет доступна только после успешного тестового письма.

1. **Почтовый сервис** — Gmail, Outlook, iCloud, Яндекс, Mail.ru или «Другой».
2. **Ваш адрес** — с этого адреса будут приходить письма.
3. **Пароль приложения** — это не ваш обычный пароль, а специальный пароль для программ. Как его получить — в [разделе 5](#5-как-получить-пароль-приложения-для-почты); рядом с полем есть ссылка «Как получить». Вставьте пароль и нажмите **«Сохранить пароль»**. Пароль хранится зашифрованным и обратно в окне не показывается (рядом будет «задан ✅»).
4. **Кому отправлять** — один или несколько адресов через запятую. Если пусто, письма идут на ваш адрес.
5. **Язык отчёта** — «Русский», «Английский», «Оба в одном письме» или «Два отдельных письма».
6. **Предупреждать о сбоях** — присылать письмо, если страну не удалось проверить два раза подряд.
7. Нажмите **«Отправить тестовое письмо»**. Программа пишет, на какие адреса оно ушло. Проверьте почту; если письма нет во «Входящих», загляните в «Спам». Когда письмо отправлено, появится «Почта: проверена ✅» и откроется «Дальше».

Если вы выбрали «Другой», появятся поля «Почтовый сервер», «Порт» и «Шифрование». Значения возьмите из справки вашего почтового сервиса. Если позже вы смените сервис или адрес, тестовое письмо нужно отправить заново.

### Шаг 4. Что искать

- **Тема** — своими словами (можно по-русски или по-английски), какие изменения вас интересуют. Уже есть готовый текст о регулировании банков и финансовых институтов; его можно оставить.
- **Для кого оценивать значимость** — чьими глазами оценивать «важно или нет». От этого зависит, какие изменения получат 🔴. Уже есть готовое описание инвестора в капитал банков; можно заменить на своё (например, «Commercial bank risk officer»).
- **Искать также в новостях** — новости дают только подсказки; всё найденное программа проверяет по официальному сайту. Выключите, чтобы расходовать меньше лимита.

### Шаг 5. Страны

Список из девяти стран с переключателями. Отметьте те, которые нужны. Адреса сайтов можно изменить позже в разделе «Страны».

### Шаг 6. Расписание

Здесь можно создать до 9 расписаний: у каждого свои дни недели, время и страны. Например, Узбекистан и Казахстан — по понедельникам, остальные — по четвергам, чтобы одна проверка не тратила весь лимит. По умолчанию — одно расписание «Основная проверка»: понедельник, 08:00, все включённые страны. Законы меняются не каждый день, раз-два в неделю достаточно.

Ниже два общих флажка:
- **Запускать при входе в систему** — чтобы проверки шли, даже если вы забыли открыть программу.
- **Если компьютер был выключен — проверить при включении** — пропущенная проверка запустится один раз, когда Mac проснётся или откроется приложение.

### Шаг 7. Проверка источников

Кнопка **«Проверить все источники»** проверяет, что сайты из списка открываются и из них можно читать новые документы. Это займёт несколько минут. Шаг можно пропустить и сделать позже в разделе «Страны». Что означают ✅, ⚠, ❌ — в [разделе 7](#7-страны-и-источники).

### Шаг 8. Готово

Покажет, когда будет следующая проверка («Следующая проверка: …»). Кнопка **«Сделать пробную проверку сейчас»** запускает проверку без письма — удобно посмотреть, как всё работает. Нажмите **«Завершить»**.

## 5. Как получить пароль приложения для почты

Почтовые сервисы не разрешают программам входить с вашим обычным паролем. Нужен отдельный **пароль приложения** — его создаёте вы сами в настройках безопасности почты. Обычно для этого в аккаунте должна быть включена двухэтапная защита (вход с кодом из SMS или приложения). Пароль показывают один раз — скопируйте его и сразу вставьте в RegWatch.

В RegWatch рядом с полем «Пароль приложения» есть ссылка «Как получить»: она открывает справку выбранного сервиса. Ссылки ниже те же. **Честное предупреждение:** адреса справок проверены автоматически 20.11.2026, но страницы не прочитаны человеком, и они могут измениться. Если ссылка не открылась или ведёт не туда, найдите нужную страницу поиском: наберите в Google или Яндексе **«app password» и название сервиса** (например, «app password Gmail»; для русскоязычных сервисов — «пароль приложения Яндекс», «пароль для внешнего приложения Mail.ru»).

| Сервис | Ссылка | Что известно |
|---|---|---|
| Gmail | https://support.google.com/accounts/answer/185833 | **Эта ссылка может отдавать «404 — страница не найдена».** Откройте её же с добавкой: https://support.google.com/accounts/answer/185833?hl=en (статья «Sign in with app passwords»). Если не открылось — ищите «app password Google» |
| Outlook | https://support.microsoft.com/account-billing/5896ed9b-4263-e681-128a-a6f2979a7944 | Открывается через перенаправление на статью «How to get and use app passwords» (на английском). Рабочие почты Microsoft 365 часто запрещают пароли приложений — спросите администратора |
| iCloud | https://support.apple.com/102654 | Открывается (на английском). Пароль создаётся на сайте Apple ID |
| Яндекс | https://yandex.ru/support/id/authorization/app-passwords.html | Открывается, ведёт на русскоязычную справку |
| Mail.ru | https://help.mail.ru/mail/security/protection/external | **Ссылка ведёт не на нужную страницу:** после перенаправления открывается общая справка по настройке почтовой программы, а не «пароль приложения». Ищите «пароль для внешнего приложения Mail.ru» или «app password mail.ru» в настройках безопасности почты |

Если не получилось: можно настроить другой почтовый ящик (например, Gmail или iCloud) — письма можно отправлять на любые адреса, не обязательно с того же сервиса.

После получения пароля: вставьте его в поле «Пароль приложения», нажмите «Сохранить пароль», затем «Отправить тестовое письмо».

## 6. Настройки по вкладкам

Раздел **Настройки** (левое меню) содержит вкладки. У каждого поля есть подсказка и пример. Кнопка **«Вернуть стандартные»** в разделе возвращает значения этого раздела по умолчанию.

### Общие
- **Язык интерфейса / Interface language** — «Русский» или «English». Это язык окон и кнопок. Язык письма выбирается отдельно, на вкладке «Почта».

### Что искать
- **Тема**, **Для кого оценивать значимость**, **Искать также в новостях** — как на шаге 4 мастера. Меняйте тему, когда нужно следить за другим кругом вопросов.

### Расписание
- Список расписаний (от 1 до 9). Кнопки: **«Добавить расписание»** (при девяти — «Больше 9 расписаний нельзя»), **«Удалить»** (последнее расписание удалить нельзя).
- У каждого расписания: **Название**, **Включено** (выключенное сохраняется, но не запускается), **Дни недели**, **Время**, **Страны** (ничего не выбрано — проверяются все включённые страны).
- Под расписанием видно, когда ближайший запуск. Если страна не входит ни в одно расписание, программа предупредит: автоматически её не проверяют. Если страна попала в два расписания в один день, программа тоже предупредит: она проверится дважды и потратит лимит.
- Общие флажки **«Запускать при входе в систему»** и **«Если компьютер был выключен — проверить при включении»**.

### Почта
Поля — как на шаге 3: **Почтовый сервис**, **Ваш адрес**, **Пароль приложения**, **Кому отправлять**, **Язык отчёта**, **Предупреждать о сбоях**, кнопка **«Отправить тестовое письмо»**. Для «Другой» — ещё **Почтовый сервер**, **Порт**, **Шифрование**. Видно состояние: «Почта: проверена ✅» или «Почта: не проверена ⚠».

### Расход
- **Режим** — «Экономно» (дешевле, чуть выше риск пропустить сложный случай), «Сбалансировано» (по умолчанию), «Максимальная точность» (дороже, самые сильные модели на важных этапах).
- **Не тратить больше X % 5-часового лимита** — ползунок от 10 до 100 % (по умолчанию 80 %). У подписки Claude есть 5-часовой лимит: он общий и с вашей обычной работой в Claude. Когда он заполнится на X %, проверка встанет на паузу до сброса лимита и потом продолжится сама. Отчёт придёт позже, но целиком. Хотите оставить запас для своей работы — поставьте меньше, например 60 %.
- **Расход последнего прогона** — только показ: по странам и этапам, в процентах лимита и в долларовом эквиваленте (по подписке доллары вы не платите; это условная мера объёма).

### Папки
- **Рабочая папка**, кнопки **«Выбрать другую»** и **«Открыть в Finder»**. Тексты инструкций модели лежат там же, но править их не нужно: при каждом запуске приложения они перезаписываются.

### Дополнительно
Свёрнуто под кнопкой «Показать дополнительные настройки». Нужно редко. Если всё работает, ничего здесь не меняйте. Внутри: модели по этапам, «Сколько минут ждать ответа», «Первый прогон страны — за сколько дней» (по умолчанию 30), «Сохранять журнал работы Claude (транскрипты)», «Путь к Claude Code» (пусто — найдётся сам), «Показать тексты скиллов» (только чтение), «Сбросить всё к стандартным» (сбрасывает все разделы, кроме пароля почты и списка стран; просит подтверждение дважды).

## 7. Страны и источники

Раздел **Страны** — таблица стран: переключатель «Участвует», название, сколько источников, их состояние, когда проверяли, итог. Выключенная страна не проверяется.

- **«Добавить страну»** — выберите из списка (начните вводить название), проверьте «Название по-русски» и «Языки», нажмите «Добавить».
- **«Проверить все источники»** — проверяет все сайты всех включённых стран.
- Клик по строке открывает **карточку страны**. Удалить страну можно кнопкой «Удалить страну» (с подтверждением); архив прошлых проверок при этом сохраняется.

### Как добавить источник

В карточке страны, раздел «Источники», кнопка **«Добавить источник»**. Заполните:
- **Адрес сайта** (начинается с https://);
- **Название** (можно оставить пустым);
- **Тип источника**: «Правовая база» (официальный сайт законодательства), «Регулятор» (центральный банк или надзорный орган), «Проекты актов» (портал обсуждения проектов), «Новости» (только подсказки, не основной источник);
- **Язык сайта** (например, ru или uz);
- **Значение** — основной или дополнительный.

После сохранения программа предложит проверить источник. У источника есть кнопки **«Изменить»**, **«Удалить»**, **«Проверить этот источник»**, переключатель **«Включён»**; у страны — **«Проверить все источники страны»**. Если какого-то типа источников у страны нет, будет кнопка **«Найти недостающие источники»**, а кнопка **«Найти основные законы»** предложит основные акты (законы о банках, об акционерных обществах и т. п.). Предложения попадают в список, только когда вы нажмёте «Добавить».

Также в карточке: **«Отслеживаемые акты»** (кнопка «Добавить акт» — название, номер регистрации, ссылка; новая редакция такого акта будет найдена, даже если тема её не поймала) и **«Органы и уровень отбора»** (кто из органов считается финансовым регулятором, а кто нет; стандартные правила уже заданы, менять обычно не нужно).

### Что значат ✅, ⚠, ❌

| Знак | Значение |
|---|---|
| ✅ | Сайт открывается, новые документы видны. Работает |
| ⚠ | Сайт открывается, но есть замечания: например, список документов появляется на странице только после загрузки «внутренних программ» сайта, и RegWatch читает его не полностью. Страна всё равно проверяется, но часть новых документов может быть не видна. Причину смотрите у источника |
| ❌ | Сайт не работает или не читается из вашей сети. Такой источник **не участвует в проверках**, пока не заработает. Прочитайте причину, исправьте адрес или проверьте источник снова |
| (пусто) | Источник ещё не проверялся |

Рядом с источником есть блок **«Что видно на сайте»** — последние документы, которые программа увидела. По нему можно понять, читает ли программа сайт.

Честно о текущем состоянии: при пробной проверке 18.11.2026 у части сайтов (в основном правовые базы Казахстана, Кыргызстана, Туркменистана, Азербайджана и Монголии) стояло ⚠, а три источника не открывались из той сети (❌). Адреса стартовых источников подобраны заранее; если какой-то сайт сменил адрес, исправьте его в карточке страны.

## 8. Запуск проверки вручную и расход

На **Главной** три кнопки:

| Кнопка | Что делает |
|---|---|
| **Проверить сейчас** | Обычная проверка: собирает, анализирует и, если есть что-то новое, отправляет письмо. Недоступна, пока не проверена почта |
| **Пробная проверка (без письма)** | То же, но письмо не отправляется, результат виден только в программе (раздел «История»). Подходит, чтобы посмотреть, как всё работает |
| **Проверить за период…** | Проверка за прошедшие даты: задайте «С» и «По», нажмите «Проверить». Письмо не отправляется |

Рядом с кнопками может появиться строка **«Оценка: ≈ …, около N % 5-часового лимита, N стран»**. Это приблизительная прикидка, сколько проверка «съест» из 5-часового лимита вашей подписки Claude (сумма в долларах — условный эквивалент). Если написано «грубая оценка, истории прогонов нет» — программа ещё не знает, сколько обычно уходит, и оценка очень приблизительна. Если появилась пометка «Проверка может занять больше одного окна лимита и встанет на паузу», проверка будет идти с остановками (см. [раздел 11](#11-пауза-по-лимиту)). Проверка за много месяцев может занять заметную часть лимита — смотрите оценку и выбирайте период разумно.

Пока идёт проверка, ниже видно окно **«Прогон»**: по каждой стране — этапы («Сбор», «Новости», «Отбор», «Экран», «Анализ», «Проверка»), сколько актов в работе и расход. Кнопка **«Остановить»** останавливает проверку; текущий шаг будет дописан, состояние сохранится. Из строки меню можно запустить то же через пункт «Проверить сейчас».

Вверху Главной видно статус: «Следующая проверка: …», «Идёт проверка: …» или «Пауза до …». Если почта не настроена, появится заметная полоса «Без настроенной почты регулярная проверка не запустится» с кнопкой «Настроить почту». Ниже есть блок «Проверка компьютера» с кнопкой «Проверить снова».

После проверки видно итог: «Проверено N из N», сколько найдено и что с письмом: «Письмо отправлено», «Письмо не требовалось: изменений нет» и т. п. Когда проверка закончилась, macOS покажет уведомление.

## 9. История

Раздел **История** — список всех проверок, новые сверху: дата, режим («По расписанию», «Проверка вручную», «Пробная проверка», «Проверка за период»), «Проверено N из N», сколько найдено («существенных», «для сведения», «не проверено») и что с письмом. Нажмите на строку, чтобы увидеть страны прогона, и выберите страну. Кнопка **«Обновить»** перечитывает список.

Внутри страны вкладки:
- **Находки** — найденные акты: «существенное», «для сведения», «не удалось проверить» (у существенных — «⚠ не подтверждено» и какие поля не подтвердились);
- **Отчёт** — подробный отчёт; переключатель языка отчёта;
- **Как проверяли** — как каждое значение сверено с текстом акта;
- **Что отброшено и почему** — акты, которые программа не взяла в разбор, и причина (всё отброшенное остаётся видимым, чтобы вы могли проверить программу);
- **Журнал** — события простыми словами;
- **Расход** — сколько ушло на эту страну.

Кнопка **«Открыть папку в Finder»** открывает папку прогона или страны.

Два способа помочь программе работать точнее:
- **«Ложное срабатывание»** — у каждой находки. Если программа показала то, что вам не нужно, нажмите и коротко напишите, почему («это не банковское регулирование», «акт уже был раньше»), затем «Отправить». Находка получит пометку «Отправлено в эталоны».
- **«Был пропущен акт…»** — у страны прогона. Если вы знаете, что важный акт программа не нашла, нажмите, вставьте ссылку на акт (начинается с http:// или https://) и комментарий — что это за акт и почему важен. Это не меняет письма, а попадает в набор контрольных случаев, по которым проверяется качество работы программы.

## 10. Почему нет письма

**Нет письма — это нормально, значит, ничего нового не нашлось.** RegWatch не шлёт письма «изменений нет». Чтобы убедиться, что проверка была, откройте **Главную** (там статус последнего прогона) или **«Историю»**: у прогона будет «Проверено 9 из 9» и «письмо не нужно». Если вы хотите убедиться, что почта работает, отправьте тестовое письмо в «Настройки → Почта».

Если письмо должно быть, а его нет, смотрите «Историю» и [частые проблемы](#12-частые-проблемы-и-что-делать): оно могло не уйти из-за пароля или связи.

## 11. Пауза по лимиту

Подписка Claude имеет 5-часовой лимит. Когда он заполняется до порога из «Настройки → Расход» (по умолчанию 80 %), RegWatch не ломается, а **встаёт на паузу**: на Главной видно «Пауза до 14:20 — ждём восстановления лимита Claude» (время условное), приходит уведомление «Проверка на паузе до …». Когда лимит восстановится, проверка **продолжится сама** с того места, где остановилась, придёт уведомление «Проверка продолжена», а письмо — после завершения, целиком. Ничего делать не нужно, только оставьте RegWatch запущенным (можно закрыть окно, значок в строке меню должен остаться).

Если почти исчерпан **недельный** лимит, страны, до которых не дошла очередь, отмечаются как «не проверена: недельный лимит почти исчерпан» и будут проверены следующим прогоном.

## 12. Частые проблемы и что делать

**«Claude Code не найден»** (❌ в «Проверке компьютера»). Откройте «Терминал» и выполните `npm install -g @anthropic-ai/claude-code`, затем наберите `claude` и войдите в аккаунт. Потом в RegWatch нажмите «Проверить снова». Если Claude Code установлен в необычное место, укажите путь в «Настройки → Дополнительно → Путь к Claude Code».

**«Вход не выполнен».** Откройте «Терминал», наберите `claude` и войдите в аккаунт. Вернитесь в RegWatch и нажмите «Проверить снова». Если вход уже выполнен, проверьте интернет.

**«Нужно обновить Claude Code»** (не хватает нужных возможностей). В «Терминале» выполните `claude update` и нажмите «Проверить снова».

**Node старой версии.** Скачайте новый установщик «LTS» на https://nodejs.org, установите, откройте «Терминал» заново.

**Тестовое письмо не уходит.** Проверьте адрес и пароль приложения: нужен именно пароль приложения, а не обычный пароль от почты. Сначала нажмите «Сохранить пароль», потом «Отправить тестовое письмо». Для сервиса «Другой» проверьте почтовый сервер, порт и шифрование по справке сервиса. Не пришло во «Входящие» — загляните в «Спам».

**Письмо с находками не ушло.** Если причина временная (нет интернета, сервер занят), RegWatch **повторяет отправку каждые 15 минут, до 6 раз**. Очередь не теряется, даже если вы перезапустите приложение. Если за это время письмо не ушло, на Главной появится «Письмо не отправлено (попыток: N)» и придёт уведомление; находки придут в следующем письме. Если причина постоянная (неверный пароль, неверный адрес), повторов нет: сразу будет «Письмо не отправлено» с пояснением. Исправьте пароль или адрес в «Настройки → Почта» и отправьте тестовое письмо.

**Mac спал или был выключен в назначенное время.** Если включён флажок «Если компьютер был выключен — проверить при включении», пропущенная проверка запустится один раз, когда Mac проснётся и RegWatch будет запущен. Чтобы проверки шли без вашего участия, включите «Запускать при входе в систему» и не выходите из RegWatch (значок в строке меню должен быть на месте).

**Проверка встала на паузу.** Это нормально — см. [раздел 11](#11-пауза-по-лимиту). Хотите, чтобы паузы были реже, — выберите «Экономно» в «Настройки → Расход» или разнесите страны по разным дням в «Расписании».

**Окно пустое или программа показывает «Что-то пошло не так».** Нажмите «Перезагрузить». Если не помогает, закройте RegWatch (значок в строке меню → «Выйти») и откройте снова из «Программ».

**«Не удаётся проверить разработчика».** См. [раздел 3](#не-удаётся-проверить-разработчика): «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

**Источник со знаком ❌ или ⚠.** См. раздел 7.

**Если ничего не помогло.** Выполните в «Терминале» (в папке проекта) `npm run doctor` и перешлите владельцу проекта текст, который она выведет, и описание, что вы делали.


Настройки, список стран, журнал и архив **сохраняются**: они лежат вне папки проекта. Перед `npm run app` программа сама закроет запущенный RegWatch.

## 14. Удаление

1. Закройте RegWatch (значок в строке меню → «Выйти»).
2. Перетащите **RegWatch.app** из папки «Программы» в корзину (если при установке не хватило прав — программа лежит в `~/Applications`).
3. Если RegWatch был в «Объектах входа», удалите его оттуда: **Системные настройки → Основные → Объекты входа**.
4. По желанию удалите данные:
   - настройки — папку `~/Library/Application Support/RegWatch`;
   - отчёты и архив — рабочую папку (по умолчанию `~/RegWatch`; если вы выбирали другую, то её);
   - скачанную папку проекта (`Jan_Analytical_news_platform`), если она больше не нужна.
5. Пароль почты хранится в зашифрованном виде в папке настроек (шаг выше его удалит). Ключ шифрования macOS держит в **«Связке ключей»** (программа «Связка ключей», запись с именем RegWatch). При желании удалите эту запись там вручную.

## 15. Где лежат файлы

| Что | Где |
|---|---|
| Программа | `/Applications/RegWatch.app` (или `~/Applications/RegWatch.app`) |
| Отчёты, архив проверок, журнал отправленного | рабочая папка, по умолчанию `~/RegWatch` (менять в «Настройки → Папки») |
| Настройки, список стран | `~/Library/Application Support/RegWatch` |
| Пароль почты | в зашифрованном виде в папке настроек; ключ — в «Связке ключей» |
| Сама программа-проект (для обновления) | папка, в которую вы скачали проект командой `git clone` |

Папку `~` Finder называет «домашней папкой»; в Finder откройте её через меню **Переход → Домой**, а скрытую «Библиотеку» — через **Переход** с зажатой клавишей Option. Рабочую папку проще открыть кнопкой «Открыть в Finder» в «Настройки → Папки».

## 16. Важно

- **RegWatch не даёт юридических консультаций.** Это помощник для первичного отбора. Каждое письмо подписано «Не является юридической консультацией». Любое важное решение проверяйте по тексту акта и с юристом.
- Для перевода: если у акта нет официального русского текста, русский текст в письме — неофициальный перевод.
- Находки с пометкой «⚠ не подтверждено» программа не смогла сверить с текстом акта — их нужно смотреть самому.
- Программа не гарантирует, что нашла всё: сайты меняются, часть сайтов читается хуже других (см. ⚠ в [разделе 7](#7-страны-и-источники)). Поэтому в письме есть строка «Проверено N из N стран» и список сбоев; а в «Истории» — что отброшено и почему.
- Все письма и отчёты основаны на официальных сайтах, указанных в разделе «Страны». Если вы добавляете источник, вы отвечаете за его надёжность.
